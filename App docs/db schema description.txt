 System is a Mobile Ordering App

Goal
-------

- System showing restaurant products to customers so that they make an order

- Customer makes an order.

- System will show in real time customers who have made orders.

- A notification is to be sent to the wait staff so that the order is processed.

- As a waiter/waitress takes an order then he/she will mark that the order taken and the order will be marked taken on the UI, alongside the waitress/waiter who has taken that order.

- System will give recommendations on products that are sold a lot and products that are not sold a lot.
	
	* This will be done on a daily, monthly and all time basis. [It will use statistic graphs and plain text explanations]

- System will show cash entered on each day, each month and all time basis. [It will use statistic graphs and plain text explanations]

- System will show the number of customer orders that the waiter/waitress has served.

	* This will be done on a daily, monthly and all time basis. [It will use statistic graphs and plain text explanations]

Database
-----------

- To store users information.

- To store authorization roles.

- To store product information.

- To store orders that customers has made.

- To store orders that has failed. (not done)

- To store wait staff (waiter/waitress) processed order.

- To store customer feedback.
